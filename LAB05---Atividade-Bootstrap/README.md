# Atividade Bootstrap (pronta para rodar)

## Como usar
1. Baixe e extraia o arquivo `.zip`.
2. Abra o `index.html` no navegador (duplo clique) ou use a extensão Live Server do VS Code.
3. Edite o conteúdo conforme sua atividade.

## Estrutura
```
atividade-bootstrap/
├─ index.html
├─ css/
│  └─ styles.css
└─ img/
   ├─ slide1.png
   ├─ slide2.png
   ├─ slide3.png
   └─ card1.png
```

> Observação: o Bootstrap é carregado via CDN. Se você **precisar rodar 100% offline**, me avise que eu preparo um pacote com os arquivos locais do Bootstrap.
